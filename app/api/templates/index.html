GoldAPI

پلتفرم هوشمند رصد قیمت‌های مالی

یک سیستم Full-Stack که نرخ ارزهای فیات و دیجیتال را به صورت لحظه‌ای اسکرپ کرده و از طریق یک API قدرتمند مبتنی بر FastAPI در اختیار توسعه‌دهندگان قرار می‌دهد.

مشاهده داشبورد خواندن مستندات

سرعت بالا (FastAPI)

بک‌اند مبتنی بر پایتون و FastAPI که یکی از سریع‌ترین فریم‌ورک‌های جهان است و درخواست‌ها را به صورت غیرهمزمان (Async) پردازش می‌کند.

ذخیره‌سازی هوشمند

استفاده از PostgreSQL به همراه زمان‌بند (APScheduler) برای ثبت تاریخچه قیمت‌ها و ارائه فایل اکسل به کاربران.

اسکرپینگ پیشرفته

استخراج داده‌های زنده با BeautifulSoup و مدیریت هدرها برای دور زدن سیستم‌های مسدودکننده (Anti-Bot).

داشبورد زنده قیمت‌ها

داده‌ها به صورت لحظه‌ای از منابع مالی استخراج و نمایش داده می‌شوند.

نام بازار قیمت لحظه‌ای بیشترین (High) کمترین (Low) تغییرات زمان بروزرسانی

در حال دریافت اطلاعات از سرور...

مستندات API (Endpoints)

از طریق مسیرهای زیر می‌توانید به داده‌های خام JSON دسترسی پیدا کنید.

GET /prices/all

دریافت لیست کامل قیمت ارزهای معمولی (دلار، یورو و ...)

// Sample Response
{
  "price_dollar_rl": {
    "name": "دلار",
    "price": 59250,
    "change": "0.71 %",
    "low": "59200",
    "high": "59600",
    "time": "15:50"
  }
}
GET /prices/coins

دریافت لیست کامل قیمت ارزهای دیجیتال (بیت‌کوین، اتریوم و ...)

GET /prices/coins/{coin_name}

دریافت اطلاعات یک ارز دیجیتال خاص با نام انگلیسی یا سیمبول آن (مثال: /prices/coins/ETH)

POST /set-schedule/{hours}

تنظیم زمان‌بندی برای ذخیره خودکار اطلاعات در دیتابیس PostgreSQL (بین ۱ تا ۶ ساعت)

GET /prices/history/{Arz_name}

دانلود فایل اکسل (Excel) تاریخچه قیمت‌های ثبت شده در دیتابیس
